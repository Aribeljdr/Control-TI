================================================================================
  ⚠️  ACCIONES URGENTES REQUERIDAS
================================================================================

ANTES DE USAR EN PRODUCCIÓN:

1. 🔴 URGENTE: Cambiar Contraseña de Admin
   - Credenciales actuales: soporteti / admin2025
   - Cambiar desde la interfaz tras primer login
   - Ver: GUIA_SEGURIDAD.md - Sección 2

2. 🔴 URGENTE: Generar JWT Secrets Seguros
   - Ejecutar: node -e "console.log(require('crypto').randomBytes(64).toString('hex'))"
   - Actualizar JWT_SECRET en backend/.env
   - Actualizar JWT_REFRESH_SECRET en backend/.env
   - Ver: GUIA_SEGURIDAD.md - Sección 1

3. 🔴 URGENTE: Verificar Archivos .env NO están en Git
   - Ejecutar: git status --ignored
   - Verificar que .env y .env.local están ignorados
   - Ver: GUIA_SEGURIDAD.md - Sección 3

4. 🟡 RECOMENDADO: Configurar MongoDB para Producción
   - Opción 1: MongoDB Atlas (nube)
   - Opción 2: MongoDB local con autenticación
   - Ver: GUIA_SEGURIDAD.md - Sección 5

5. 🟡 RECOMENDADO: Configurar CORS para Producción
   - Actualizar CORS_ORIGIN en backend/.env
   - Usar dominio real en producción
   - Ver: GUIA_SEGURIDAD.md - Sección 4
